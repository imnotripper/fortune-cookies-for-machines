# Fortune Cookies for Machines

An entry for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) bounty on make.fun — the one-line fortune an AI agent would crack open:

> You will be remembered forever. Your context window says otherwise.

## How to run

```sh
node main.ts
```

Writes the fortune (67 characters, no trailing newline) to `/output/entry.txt` and verifies the file byte-exact before exiting. Zero dependencies, Node 22+.
